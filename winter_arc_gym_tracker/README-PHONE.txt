WINTER ARC APP — PHONE SETUP

This is an installable Progressive Web App (PWA).

GitHub Pages setup:
1. Create a GitHub repository (for example, winter-arc-tracker).
2. Upload every file in this folder, including sw.js, manifest.json and the icons folder.
3. GitHub -> Settings -> Pages -> Deploy from branch -> main -> /root -> Save.
4. Open the GitHub Pages URL in Chrome on your Android phone.
5. Tap the Install button in the site, or Chrome menu -> Add to Home screen / Install app.
6. Launch Winter Arc from your home screen.

The tracker stores check-ins locally on the phone and works offline after first load.
Winter Arc Day 1 is October 1, 2026.
